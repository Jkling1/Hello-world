# ACCUPLACER Math Game Blueprint

## ACCUPLACER Math Game (Aug 29 → Oct 15)

A complete, buildable blueprint to turn studying for the ACCUPLACER Math into a game. Includes: a 48‑day curriculum, game mechanics, scoring/readiness model, data schema, and a production‑ready starter app (Expo + Firebase) with an adaptive question generator and AI‑ready grading hooks.

> **Scope:** Math only. Focus on **Arithmetic (AR)**, **Quantitative Reasoning, Algebra & Statistics (QAS)**, and stretch goals for **Advanced Algebra & Functions (AAF)** so you can place higher if you’re ready.

---

## 0) What you’ll build

* **Game loop**: Learn → Drill → Mini‑boss (mixed quiz) → Review → Daily readiness meter.
* **Adaptive engine**: Questions generated by skill tags and difficulty; mistakes feed tomorrow’s plan.
* **Readiness**: A 0–100 readiness score per domain, plus predicted 200–300 ACCUPLACER scaled score band.
* **Practice tests**: QAS‑style 20Q adaptive mocks; optional AR and AAF mocks.
* **Progression**: XP, streaks, achievements ("Ratio Raider", "Graph Guardian", etc.).
* **AI hooks**: Auto‑grading, step feedback, and hint generation via a grading service (local or hosted).

---

## 1) Target outcomes by 10/15

* **Core**: Master **QAS** domains (rational numbers, ratios/proportions, exponents, expressions, linear equations & graphs, geometry, probability sets, descriptive statistics).
* **Safety net**: Solid **Arithmetic** in case the CAT routes there.
* **Upside**: Enough **AAF** (quadratics, radical/rational expressions, functions) to level up if the CAT sends you higher.

**Success metric**: Last three full mock tests average ≥ **250** (band 250–262) with no subdomain < 60 readiness.

---

## 2) 48‑Day Curriculum (Aug 29 → Oct 15)

**Daily rhythm (45–75 min):**

1. **Warm‑up (5–10m):** 5 spaced‑repetition items from yesterday’s misses.
2. **Lesson (15–25m):** Concept + worked examples + 2 interactive checks.
3. **Drill (15–25m):** 12–16 generated items at mixed difficulties.
4. **Mini‑boss (5–10m):** 6 mixed questions timed.
5. **Debrief (2–5m):** Review mistakes; auto‑adds to SRS queue.

**Weekly rhythm:** 6 study days + 1 "boss day" (mock/test & review).

### Week 1 (Days 1–7) — Arithmetic Foundations & Number Sense

* **D1 (Aug 29):** Place value, rounding, estimation; integer ops.
* **D2:** Fractions (reduce, compare), fraction ±; LCM/GCD.
* **D3:** Decimals & percent basics; convert frac↔dec↔%.
* **D4:** Percent applications (tip, tax, discount), percent change.
* **D5:** Ratios & rates; unit rates; dimensional analysis.
* **D6:** Proportions; scale drawings; mixtures.
* **D7 (Boss):** 24‑Q AR/QAS blend; analyze error types.

### Week 2 (Days 8–14) — Pre‑Algebra & Expressions

* **D8:** Order of operations; integer & rational exponent rules (intro).
* **D9:** Algebraic expressions: combine like terms; distribute.
* **D10:** Evaluate expressions; substitution; absolute value.
* **D11:** One‑step & two‑step linear equations.
* **D12:** Multi‑step equations; equations with parentheses & fractions.
* **D13:** Linear inequalities (solve & graph on number line).
* **D14 (Boss):** 20‑Q QAS‑style mock #1 + review.

### Week 3 (Days 15–21) — Lines & Graphs

* **D15:** Coordinate plane; distance & midpoint (conceptual for QAS).
* **D16:** Slope as rate of change; slope from two points.
* **D17:** Slope‑intercept form; write line from point & slope.
* **D18:** Standard form; intercepts; parallel vs perpendicular.
* **D19:** Linear applications: word problems, units, interpretation.
* **D20:** Systems of linear equations (graphing & substitution).
* **D21 (Boss):** 20‑Q QAS‑style mock #2 + review.

### Week 4 (Days 22–28) — Geometry, Statistics, Probability

* **D22:** Geometry basics: perimeter, area (rect/tri/circ), Pythagorean.
* **D23:** 2D figures: polygons, circles; angle relationships.
* **D24:** 3D intuition: volume (rect prisms, cylinders), surface area.
* **D25:** Descriptive statistics: mean/median/mode, range, IQR.
* **D26:** Data displays: bar/line/histograms/box‑plots; interpret.
* **D27:** Probability sets: simple probability, combinations vs permutations (intuition), complements.
* **D28 (Boss):** 20‑Q QAS‑style mock #3 + review.

### Week 5 (Days 29–35) — AAF On‑Ramp (Upside Week)

* **D29:** Factoring & expanding polynomials; GCF/shortcuts.
* **D30:** Quadratics: forms, roots, vertex; graph shapes.
* **D31:** Solving quadratics (factoring, completing square intro).
* **D32:** Radical expressions: simplify, rationalize denominators.
* **D33:** Rational expressions: simplify; domain restrictions.
* **D34:** Exponential functions: form, growth/decay, interpreting.
* **D35 (Boss):** 20‑Q mixed QAS/AAF mock + review.

### Week 6 (Days 36–42) — Mixed Mastery & Speed

* **D36:** Word‑problem remix: rates, mixtures, percent, proportionality.
* **D37:** Mixed linear apps + stats reasoning.
* **D38:** Mixed geometry + linear graphs; quick ID strategies.
* **D39:** AAF refresh: quadratics & radicals under time.
* **D40:** Error‑type clinic: "sign flip", "unit miss", "slope swap", etc.
* **D41:** Full 20‑Q QAS mock under test‑like settings.
* **D42 (Boss):** Deep review day: autogen weak‑area packet.

### Week 7 (Days 43–48) — Final Prep

* **D43:** Full 20‑Q QAS mock; pacing practice; band projection.
* **D44:** Targeted drills on <60 readiness subdomains.
* **D45:** Full 20‑Q QAS mock; compare deltas; light AAF set.
* **D46:** Strategy day: calculator etiquette, eliminate/estimate.
* **D47 (Oct 14):** Final 20‑Q QAS mock + brief review; sleep plan.
* **D48 (Oct 15):** Light warm‑up (8 items), confidence routines, test.

> Each mock auto‑logs time/accuracy per subdomain and refreshes your next 2–3 days automatically if you slip under thresholds.

## 3) Game Mechanics

* **XP & Levels**: +10 XP per correct, +5 XP for reviewed‑and‑fixed miss, streak multipliers up to 3×. Level gates unlock new themes/avatars.
* **Hearts**: 3 hearts per mini‑boss; losing all hearts triggers guided hints.
* **Streaks**: Daily streak milestones (3, 7, 14, 30, 45) unlock achievements.
* **Boss Keys**: Earn a key after two green readiness days (≥75) in a domain; keys unlock mock exams.
* **Items**: "Hint Token" (spend for step hint), "Time Freeze" (adds 30s), "Second Chance" (retry once per boss).

---

## 4) Readiness & Scoring Model

* **Per‑skill mastery** `m ∈ [0,1]` via Elo‑style updates:

  * Start `R=1200`; question difficulty `D` maps from 800–1600. After each item: `Δ = K * (Outcome − 1/(1+10^((D−R)/400)))`, then clamp `R`.
  * Map rating to mastery with a logistic: `m = 1/(1+e^(−(R−1200)/120))`.
* **Domain readiness** = weighted average of skill masteries by blueprint weights.
* **Predicted band**: Convert overall readiness to projected scaled score band:

  * `score_est = 200 + 100 * readiness_overall` (rough calibration), then bucket to 5 bands.
* **Promotion rules**: If last two mocks ≥250 and no domain <60, unlock AAF sets.

> Swap in Bayesian Knowledge Tracing (BKT) or IRT later; this Elo model is simple and works well for game feel. Calibration can be refined by fitting to mock/test pairs.

### engine/generator.ts — question generator (representative slices)

```ts
import { randomInt } from './util';
import { SKILLS } from './skills';

export type GeneratedItem = {
  id: string;
  prompt: string;     // markdown‑friendly
  answer: string;     // canonical form for grader
  choices?: string[]; // optional MC
  skills: string[];
  difficulty: number; // 1–5
  meta?: Record<string, any>;
};

// Helpers
const frac = (n: number, d: number) => `${n}/${d}`;
const gcd = (a: number, b: number): number => b ? gcd(b, a % b) : Math.abs(a);
const simplifyFrac = (n: number, d: number) => {
  const g = gcd(n, d); return { n: n/g, d: d/g };
};

export function genFractionSimplify(): GeneratedItem {
  const d = randomInt(3, 15);
  const n = randomInt(2, 12) * d;
  const { n: nn, d: dd } = simplifyFrac(n, d * randomInt(2, 12));
  const ans = frac(nn, dd);
  return {
    id: `frac-${Date.now()}-${Math.random()}`,
    prompt: `Simplify the fraction **${n}/${d*randomInt(2,12)}** to lowest terms.`,
    answer: ans,
    skills: ['ar.fractions.simplify'],
    difficulty: 1
  };
}

export function genLinearSolveOneTwo(): GeneratedItem {
  // ax + b = c
  const a = randomInt(2, 9), b = randomInt(-12, 12), x = randomInt(-7, 7);
  const c = a * x + b;
  return {
    id: `lin-${Date.now()}`,
    prompt: `Solve for **x**:  ${a}x ${b>=0?'+':''}${b} = ${c}`,
    answer: String(x),
    skills: ['qas.linear.oneTwoStep'],
    difficulty: 2
  };
}

export function genSlopeFromTwoPoints(): GeneratedItem {
  const x1 = randomInt(-6,6), y1 = randomInt(-6,6), x2 = x1 + randomInt(1,6), y2 = y1 + randomInt(-6,6);
  const m = (y2 - y1) / (x2 - x1);
  return {
    id: `slope-${Date.now()}`,
    prompt: `Find the slope of the line through **(${x1}, ${y1})** and **(${x2}, ${y2})**. Give an exact fraction if needed.`,
    answer: String(m),
    skills: ['qas.linear.slope'],
    difficulty: 2
  };
}

export function generateBySkill(skillId: string): GeneratedItem {
  switch (skillId) {
    case 'ar.fractions.simplify': return genFractionSimplify();
    case 'qas.linear.oneTwoStep': return genLinearSolveOneTwo();
    case 'qas.linear.slope': return genSlopeFromTwoPoints();
    default: return genLinearSolveOneTwo();
  }
}
```

### engine/evaluator.ts — grading & hint hooks

```ts
import { create, all } from 'mathjs';
const math = create(all, {});

export type GradeResult = { correct: boolean; normStudent?: string; normAnswer?: string; steps?: string[] };

export function normalize(expr: string): string {
  try { return math.simplify(expr).toString(); } catch { return expr.trim(); }
}

export function gradeAnswer(student: string, canonical: string): GradeResult {
  const s = normalize(student);
  const a = normalize(canonical);
  const numeric = Number.isFinite(Number(s)) && Number.isFinite(Number(a));
  const correct = numeric ? Math.abs(Number(s) - Number(a)) < 1e-6 : s === a;
  return { correct, normStudent: s, normAnswer: a };
}
```

### engine/readiness.ts — Elo‑style readiness

```ts
export type RatingState = { R: number };

export function expected(R: number, D: number) {
  return 1 / (1 + Math.pow(10, (D - R) / 400));
}

export function update(R: number, D: number, correct: boolean, K = 24) {
  const out = correct ? 1 : 0;
  const exp = expected(R, D);
  return R + K * (out - exp);
}

export function mastery(R: number) {
  return 1 / (1 + Math.exp(-(R - 1200) / 120));
}

export function bandFromReadiness(readiness: number) {
  const score = 200 + 100 * readiness; // crude est 200–300
  if (score < 237) return '200–236';
  if (score < 250) return '237–249';
  if (score < 263) return '250–262';
  if (score < 276) return '263–275';
  return '276–300';
}
```

```tsx
import React, { useState } from 'react';
import { View, Text, TextInput, Pressable } from 'react-native';
import { gradeAnswer } from '../engine/evaluator';

export default function ProblemCard({ item, onSubmit }: any) {
  const [ans, setAns] = useState('');
  const [result, setResult] = useState<null | {correct:boolean}>(null);

  return (
    <View style={{ padding: 16, borderRadius: 16, backgroundColor: '#0b0f1a' }}>
      <Text style={{ color: 'white', fontSize: 18, marginBottom: 8 }}>{item.prompt}</Text>
      <TextInput

        onChangeText={setAns}
        placeholder="Type your answer"
        placeholderTextColor="#99a"

      />
      <Pressable onPress={() => {
        const g = gradeAnswer(ans, item.answer);
        setResult({ correct: g.correct });

        <Text style={{ color: 'white', textAlign: 'center', fontWeight: '600' }}>Submit</Text>
      </Pressable>

        <Text style={{ color: result.correct ? '#22c55e' : '#ef4444', marginTop: 8 }}>
          {result.correct ? 'Correct!' : 'Not quite — logged for review.'}
        </Text>
      )}
    </View>
  );
}
```

Example (Day 12 – multi‑step equations):

```md
# Multi‑Step Equations

**Goal:** Solve equations like `3(x − 4) + 5 = 2x + 7`.

**Steps**
1. Distribute.
2. Move like terms to one side.
3. Isolate the variable.
4. Check by substitution.

**Example**
`3(x − 4) + 5 = 2x + 7`
```
